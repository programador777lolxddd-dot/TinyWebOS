# TinyWebOS

TinyWebOS es un proyecto de **WebOS de código abierto** que busca combinar la ligereza de [Tiny Core Linux](http://tinycorelinux.net/) con una interfaz de escritorio accesible desde el navegador. La idea es ofrecer un entorno mínimo, rápido y fácil de personalizar, ideal para aprender, experimentar y reutilizar en hardware modesto.

> ⚠️ **Estado del proyecto:** En desarrollo temprano (alpha). Actualmente el repositorio contiene únicamente el esqueleto inicial de la interfaz web (`tinyweb.html`). Todavía no hay una ISO funcional ni un escritorio completo.

---

## 🚀 Características previstas

- Interfaz de escritorio web ligera y responsive.
- Base en Tiny Core Linux para un arranque rápido y bajo consumo de recursos.
- Gestor de ventanas y lanzador de aplicaciones (en desarrollo).
- Aplicaciones básicas integradas (terminal, editor de texto, navegador, etc.).
- Posibilidad de ejecutarse en máquina virtual, USB o hardware real.
- Código abierto y documentado para facilitar la colaboración.

---

## 📦 Requisitos

Por ahora, para probar la parte web solo necesitas:

- Un navegador moderno (Chrome, Firefox, Edge, etc.).
- Git (opcional, para clonar el repositorio).

Para la futura ISO de TinyWebOS (aún no publicada) se necesitará:

- Una máquina virtual (VirtualBox, QEMU, VMware) o un equipo físico.
- Una memoria USB (si se desea instalar en hardware real).
