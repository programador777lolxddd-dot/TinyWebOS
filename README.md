### 📦 Instalación y Uso

<details style="background-color: #161b22; padding: 15px; border-radius: 10px; border: 1px solid #30363d;">
  <summary><b>🛠️ Hacer Deploy Local (Clic para expandir)</b></summary>
  <br>
  
  ```bash
  # 1. Clona el repositorio
  git clone https://github.com/programador777lolxddd-dot/TinyWebOS.git
  
  # 2. Entra al directorio
  cd TinyWebOS
  
  # 3. Ejecuta el sistema (Solo abre el archivo)
  # En Windows: start tinyweb.html
  # En macOS: open tinyweb.html
  # En Linux: xdg-open tinyweb.html
