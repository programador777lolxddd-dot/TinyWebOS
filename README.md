TinyWebOS es un proyecto de **WebOS de código abierto** que busca combinar la ligereza de [Tiny Core Linux](http://tinycorelinux.net/) con una interfaz de escritorio accesible desde el navegador. La idea es ofrecer un entorno mínimo, rápido y fácil de personalizar, ideal para aprender, experimentar y reutilizar en hardware modesto.

> ⚠️ **Estado del proyecto:** Beta funcional. El escritorio web está completo en un solo archivo HTML, incluyendo gestor de ventanas, sistema de archivos virtual, terminal, 14 aplicaciones y asistente IA.

---

## 🚀 Características

- Interfaz de escritorio web ligera y responsive.
- Base en Tiny Core Linux para un arranque rápido y bajo consumo de recursos.
- Gestor de ventanas (arrastrar, redimensionar, minimizar, maximizar).
- Terminal con comandos reales sobre un sistema de archivos virtual persistente.
- Aplicaciones integradas: Editor, Calculadora, Notas, Navegador, Pintura, Snake, Sintetizador, Monitor del Sistema, Ajustes.
- Asistente IA integrado con Gemini (streaming en tiempo real).
- Sin frameworks ni dependencias externas. Todo es HTML, CSS y JS puro.
